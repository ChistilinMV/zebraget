# Zebraget — мобильный каталог товаров

**Zebraget** — это клиент-серверный комплекс для учета и каталогизации товаров. Проект состоит из мобильного приложения (клиента), поддерживающего поиск штрихкодов товаров и работу в офлайн-режиме, а также серверной части (на базе Node.js), обеспечивающей синхронизацию данных, управление пользователями и администрирование контента.

## Основные возможности мобильного приложения:
- 📦 **Каталог товаров:** Группировка и удобный просмотр товаров.
- 🏷️ **Сканирование штрихкодов:** Быстрый поиск штрихкодов товаров по наименованию.
- 📶 **Офлайн-режим:** Возможность работы без интернета с последующей синхронизацией.
- 🔄 **Синхронизация:** Обмен данными с выделенным сервером.

## Панель администратора (Web)
Серверная часть включает в себя веб-интерфейс администратора, предоставляющий следующие возможности:
- 🗂️ **Управление каталогом:** Создание, редактирование и удаление групп и товаров. Защита от удаления групп, содержащих товары.
- 👥 **Управление пользователями:** Добавление пользователей мобильного приложения, изменение их паролей и лимитов на количество устройств.
- 🔄 **Импорт и экспорт:** Выгрузка базы данных (товаров и групп) в формате XLSX и JSON для резервного копирования и загрузки (импорта) данных на сервер.

## Аутентификация и учет сессий
Безопасность и контроль доступа реализованы с разделением на администратора и клиентов:
- **Администратор:** Вход по мастер-паролю с генерацией токена, который хранится в памяти сервера.
- **Мобильные клиенты:** Авторизация по логину, паролю и уникальному идентификатору устройства (`deviceId`). Сессии сохраняются в базе данных сервера.
- **Контроль устройств:** Для каждого пользователя настраивается лимит одновременно используемых устройств (по умолчанию 2). При исчерпании лимита вход с нового устройства блокируется.
- **Управление сессиями:** Администратор видит количество активных устройств у каждого пользователя и может точечно удалять (отзывать) сессии конкретных устройств.
